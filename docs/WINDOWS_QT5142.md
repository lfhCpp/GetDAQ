# Windows control GUI

The supported product boundary is [PRODUCT_SCOPE.md](PRODUCT_SCOPE.md).
Windows is a control-GUI build target; original backend processes are deployed
on POSIX hosts. Use the Qt 5 kit matching your compiler and architecture.
The old native ECC/supervisor control tools and their test recipes are retired.

The current cleanup was compiled and tested on Linux. A fresh Windows build
and hardware connection must be verified before treating Windows as validated.
